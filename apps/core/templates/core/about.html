About

SCD Activity Reporting System

Fermilab Scientific Computing Division

SCD Activity Reporting is a web application developed by staff at Fermi National Accelerator Laboratory (Fermilab) for use by the Scientific Computing Division. It provides a structured way for SCD personnel to log weekly effort entries against projects, categories, and performance goals, and allows administrators and group leaders to filter, review, export, and summarize that activity using both standard reports and AI-assisted narrative summaries.

Internal use only. This application is intended exclusively for Fermilab SCD staff. Unauthorized access or use is prohibited.
