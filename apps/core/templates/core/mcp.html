Connect an AI assistant (MCP)

SCD Reporting provides a Model Context Protocol server so that Claude Code, Claude Desktop and other MCP clients can read and post entries, run reports and generate summaries for you. The server is a small program that runs on your computer, started by the client. It talks to this site through the token API using your personal API token, so it can see and do exactly what you can.

{% comment %}— Step 1 ————————————————————————————————————{% endcomment %}

1. Get the client files

The MCP server and the command-line tools are in the scripts/ directory of the project repository. You will need to checkout the latest version of the repository. Then make sure to keep scd-mcp, scd_mcp.py and scd_client.py together.

git clone {{ repo_url }}.git ~/SCD-Reporting
{% comment %}— Step 2 ————————————————————————————————————{% endcomment %}

2. Save the server URL and your token

You will need an API token to authenticate with the MCP server. Get this by clicking on your name in the scd-reporting interface and then generating a new token. Copy it to the clipboard. The MCP server reads the same settings as the scd-* command-line tools. For security reasons put the token in a client configuration file which will be used by the MCP server.

Linux and macOS

mkdir -p ~/.config/scd-reporting
cat > ~/.config/scd-reporting/config.yaml <<'EOF'
url: {{ site_url }}
token_file: ~/.config/scd-reporting/token
EOF
echo -n "Paste API token: " && read -rs T && printf '%s\n' "$T" > ~/.config/scd-reporting/token && unset T
chmod 600 ~/.config/scd-reporting/token

Windows 11 (PowerShell)

$d = "$HOME\.config\scd-reporting"; New-Item -ItemType Directory -Force $d | Out-Null
"url: {{ site_url }}`ntoken_file: $d\token" | Set-Content "$d\config.yaml"
Read-Host "Paste API token" | Set-Content "$d\token"

Check it with python3 ~/SCD-Reporting/scripts/scd-whoami, which should print your name and role.

Precedence for every setting: command-line option > environment (SCD_URL, SCD_TOKEN, SCD_TOKEN_FILE, …) > .env > config file. scd-whoami --settings shows where each value came from.

{% comment %}— Step 3 ————————————————————————————————————{% endcomment %}

3. Register the server with your client

Claude Code: every project (user scope)

claude mcp add --scope user scd-reporting -- python3 ~/SCD-Reporting/scripts/scd-mcp

Windows (PowerShell): claude mcp add --scope user scd-reporting -- py "$HOME\SCD-Reporting\scripts\scd-mcp"

Without a config file, pass the settings as environment variables instead: claude mcp add --scope user scd-reporting -e SCD_URL={{ site_url }} -e SCD_TOKEN_FILE=~/.config/scd-reporting/token -- python3 ~/SCD-Reporting/scripts/scd-mcp

Claude Code: inside the SCD-Reporting checkout (project scope)

The repository already contains a .mcp.json that registers this server. Start claude in the checkout and approve scd-reporting when asked.

Claude Desktop and other MCP clients

Add this to the client's server list (Claude Desktop: Settings → Developer → Edit Config, claude_desktop_config.json). Use absolute paths; on Windows use "command": "py" and a C:\\… path.

{
  "mcpServers": {
    "scd-reporting": {
      "command": "python3",
      "args": ["/Users/YOU/SCD-Reporting/scripts/scd-mcp"],
      "env": { "SCD_URL": "{{ site_url }}" }
    }
  }
}
{% comment %}— Step 4 ————————————————————————————————————{% endcomment %}

4. Check the connection

claude mcp list                                   # scd-reporting should show "Connected"
python3 ~/SCD-Reporting/scripts/scd-mcp --list-tools  # tools the server will offer

Then, in a Claude Code session, run /mcp to see the server and its tools, or simply ask: “Using scd-reporting, who am I?”

{% comment %}— Troubleshooting ——————————————————————————{% endcomment %}

Troubleshooting and security

“HTTP 401” from a tool
The token is missing, wrong or was regenerated. Copy the current one from Profile into your token file.
“HTTP 403” from a report tool
Your role cannot run reports. Your own entries are still available through the entry tools.
“No server URL” or “No API token”
The server could not find its settings. Run scd-whoami --settings in a terminal; the client starts the server with your normal home directory and environment.
Certificate errors
Point ca_bundle: in the config file (or SCD_CA_BUNDLE) at a PEM file that includes the Fermilab CA.
Server log
The server writes diagnostics to standard error, which Claude Code shows with claude --debug or in /mcp.
What the assistant can do
Everything your token can: read what you can read, export (each export is audit-logged), and post entries under your name. Revoke or regenerate the token on your Profile to cut off access immediately.
